# Créditos de las fotografías reales de Quito

Las fotografías se muestran como postales pequeñas en el juego y como tarjeta al inicio de cada nivel. Se cargan **en línea** desde Wikimedia Commons: el ZIP no contiene copias de las fotografías, pero las cuatro URL ya están configuradas en `js/photos.js`. Si una imagen no se puede descargar, el videojuego sigue funcionando y muestra un dibujo de respaldo. Es necesaria conexión a Internet para las fotografías, además de para cargar Phaser 3 desde su CDN.

**Transformaciones realizadas:** las imágenes se recortan automáticamente al formato de postal y se reducen de tamaño dentro del videojuego; no se alteran los elementos representados. Las licencias exigen atribución y que las adaptaciones fotográficas se compartan bajo una licencia compatible. Las fotografías mantienen sus propias licencias, distintas de las aplicables al código del juego.

Puedes sustituir las URLs del arreglo `photos` de `js/photos.js` por fotografías propias, conservando el nombre de cada etapa y revisando las licencias correspondientes. Si publicas el proyecto en GitHub Pages, mantén este archivo de créditos.
